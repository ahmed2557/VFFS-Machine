      Link details

      Modbus settings (in the ESP32)

      8 data bits, no parity, 1 stop bit. Reads registers 100 to 139, writes 200 to 215.

      Test panel

      You are connected to the test machine, a simulation inside this page. Nothing is sent to a real machine. It answers like the PLC: same limits, same rules, same messages. Control PIN: 1234.

      Switches on the machine and the HMI

      Faults

      A fault stops the machine (state Fault). Clear the cause here, then press Reset on the Control page.

      Your test data

      How to test

      1. Control: press Start. The test machine goes Homing, Preheat, Filling, Running.
      2. Change the target speed to 60 with a 120 mm bag: the PLC check refuses it (film too fast).
      3. Here: switch Remote control off, then try Start: refused. Stop still works.
      4. Here: turn the manual selector on (machine in Idle), then use the Manual page.
      5. Here: raise a fault, watch the banner, the alarm log and the state.
      6. Here: cut the PLC link or the Wi-Fi, and see how every page reacts.
